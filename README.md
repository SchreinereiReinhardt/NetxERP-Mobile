# NextERP Mobile

NextERP Mobile 0.7.0 mit Jetpack Compose und echtem Nextcloud-Login über die OCS-Benutzerschnittstelle.

## Öffnen
Den Ordner öffnen, in dem `settings.gradle.kts` liegt. Danach Gradle synchronisieren und das Modul `app` starten.

## Login
Server: `https://cloud.kassel-net.de`

Empfohlen wird ein eigenes Nextcloud-App-Passwort. Alternativ kann die Oberfläche über `Demo öffnen` ohne Server getestet werden.
